# Fictional Persona example

This directory is a complete fictional example with 30 Q&A pairs for documentation and open-source releases.

- It contains no facts, writing samples, contact details, or projects from the repository owner.
- `manifest.yaml` is marked `example_only: true` and `approved: false`.
- It must never be used as evidence about a real person.
- It is intentionally not production-ready; adopters must create and approve their own private Persona package.
